# Atlas Agent Framework 1.1.0rc2

## Objetivo

A candidata `1.1.0rc2` reabre a certificação do M01 — Durable State após a
falha de infraestrutura observada na RC1. O conteúdo funcional do framework é
preservado.

## Motivo da nova candidata

O workflow da `v1.1.0rc1` aprovou qualidade nas quatro combinações de sistema
operacional e Python, segurança, exemplos, builds reproduzíveis, instalação
limpa, SBOM, checksums, Bandit e `pip-audit`. O job final, porém, executou a
cobertura sem PostgreSQL e Redis, ignorou 128 integrações e registrou 89,61%,
abaixo do threshold bloqueante de 90%.

## Delta autorizado

- versão lockstep alterada para `1.1.0rc2`;
- job `certificar-artefatos` equipado com PostgreSQL 16 e Redis 7.4 reais;
- variáveis de conexão limitadas ao job de certificação;
- teste de regressão para preservar essa infraestrutura;
- changelog e documentação de release atualizados.

Não há alteração funcional, de API pública, dependência de runtime, contrato,
schema persistido ou política de segurança.

## Governança

A tag `v1.1.0rc1` não será reescrita nem reutilizada. A `v1.1.0rc2` exigirá
novo commit, nova tag anotada, novos artefatos e certificação integral. Nenhuma
dessas etapas autoriza publicação no PyPI.
