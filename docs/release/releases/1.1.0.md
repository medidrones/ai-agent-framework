# Atlas Agent Framework 1.1.0

> Gate técnico de promoção `PASS`; versão estável `PUBLISHED`.
> Tag, GitHub Release e sete distribuições no PyPI foram verificadas.

## Resumo

Esta versão promove a candidata certificada `1.1.0rc2` pela rota não
destrutiva. Ela entrega o M01 — Durable State e preserva o nome público
`atlas-agent-framework`, o namespace importável `atlas_agent` e os contratos
públicos do Atlas 1.x.

## Conteúdo estável

- contratos provider-neutral de checkpoint durável, leases, fencing,
  retenção, purge e coordenação de recovery;
- adapters opcionais PostgreSQL e Redis, sem dependências de infraestrutura no
  core;
- retomada HITL durável, consumo atômico e proteção contra replay;
- certificações de crash recovery, Kubernetes, desempenho e carga.

## Delta autorizado

- remoção do sufixo `rc2` das versões das sete distribuições;
- sincronização das restrições internas lockstep e do lockfile;
- atualização de changelog, README, notas e evidências de release;
- geração de novos artefatos, checksums e SBOM da versão estável.

Não há nova funcionalidade, alteração de API pública, dependência externa,
arquitetura, schema, wire contract, política de segurança ou desativação de
testes.

## Publicação

O [gate de promoção](../STABLE-PROMOTION-STATUS.md) certificou os artefatos
instalados em ambientes limpos e comprovou delta restrito a versionamento e
release metadata. A tag anotada
[`v1.1.0`](https://github.com/medidrones/ai-agent-framework/releases/tag/v1.1.0)
aponta ao commit certificado e a GitHub Release contém sete wheels, sete
sdists, SBOM e `SHA256SUMS`.

As sete distribuições foram publicadas por Trusted Publishing, sem token de
longo prazo, em três lotes sequenciais:

- [atlas-agent-core](https://pypi.org/project/atlas-agent-core/1.1.0/),
  [atlas-agent-adapters](https://pypi.org/project/atlas-agent-adapters/1.1.0/)
  e [atlas-agent-config](https://pypi.org/project/atlas-agent-config/1.1.0/);
- [atlas-agent-evaluation](https://pypi.org/project/atlas-agent-evaluation/1.1.0/),
  [atlas-agent-framework](https://pypi.org/project/atlas-agent-framework/1.1.0/)
  e [atlas-agent-mcp](https://pypi.org/project/atlas-agent-mcp/1.1.0/);
- [atlas-agent-providers](https://pypi.org/project/atlas-agent-providers/1.1.0/).

Cada projeto possui exatamente um wheel e um sdist, e os 14 hashes foram
comparados com o manifesto certificado após a publicação.
