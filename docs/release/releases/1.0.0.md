# Atlas Agent Framework 1.0.0

> Esta release foi publicada no GitHub, mas não no PyPI. A publicação no índice
> foi bloqueada porque `atlas-agent` pertence a outro projeto. A correção segue
> na candidata `1.0.0rc4`, com o meta-package `atlas-agent-framework`.

## Resumo

A versão `1.0.0` é a promoção estável da candidata certificada
`1.0.0rc3`. O delta de promoção está limitado a versionamento, restrições
internas lockstep, changelog, notas e evidências de release. Não há alteração
funcional, de API, dependência, arquitetura, contrato, schema ou política de
segurança.

Os artefatos estáveis são preparados e certificados separadamente. A decisão
`READY_TO_PUBLISH` não publica pacotes automaticamente. Qualquer envio ao
PyPI ou a outro registry exige autorização explícita e ambiente protegido.
