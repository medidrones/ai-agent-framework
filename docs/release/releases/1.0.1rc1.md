# Atlas Agent Framework 1.0.1rc1

## Objetivo

A candidata `1.0.1rc1` abre a rota não destrutiva para a versão estável
`1.0.1`. Ela preserva as tags `v1.0.0` e `v1.0.0rc5` e evita reescrever
qualquer referência já publicada.

## Origem

O conteúdo técnico deriva do `1.0.0rc5`, certificado no commit
`ab90d270da95a405a58b6cd3688d7d26863288cc`, com os cinco owner sign-offs em
`PASS` e decisão `READY_FOR_STABLE`.

## Delta autorizado

- versão lockstep alterada para `1.0.1rc1`;
- restrições internas sincronizadas para a mesma candidata;
- documentação e metadata específicas do novo ciclo de release.

Não há alteração funcional, de API pública, namespace Python, dependência
externa, arquitetura, wire contract, schema de configuração ou política de
segurança.

## Publicação

Esta candidata não autoriza publicação no PyPI. A promoção para `1.0.1` exige
certificação integral dos novos artefatos, novos sign-offs e autorização
explícita para a etapa de publicação.
