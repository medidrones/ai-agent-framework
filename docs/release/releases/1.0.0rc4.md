# Atlas Agent Framework 1.0.0rc4

## Objetivo

A candidata `1.0.0rc4` corrige exclusivamente a identidade pública do
meta-package antes da publicação no PyPI. O nome `atlas-agent` pertence ao
projeto de terceiros Feng Lab e não pode representar o Atlas Agent Framework.

## Alteração autorizada

- novo nome da distribuição: `atlas-agent-framework`;
- namespace Python preservado: `atlas_agent`;
- seis distribuições auxiliares preservadas;
- versão lockstep: `1.0.0rc4`;
- scripts, testes, documentação e metadata alinhados ao novo nome.

Não há alteração de comportamento funcional, API pública, arquitetura, wire
contract, schema de configuração, dependência externa ou política de segurança.

## Disponibilidade no registry

Em 14 de setembro de 2026, a API oficial do PyPI retornou projeto inexistente
para os sete nomes planejados:

- `atlas-agent-framework`;
- `atlas-agent-core`;
- `atlas-agent-adapters`;
- `atlas-agent-config`;
- `atlas-agent-evaluation`;
- `atlas-agent-mcp`;
- `atlas-agent-providers`.

A disponibilidade não constitui reserva. A certificação deve repetir essa
consulta imediatamente antes da publicação autenticada.

## Situação da publicação

Esta candidata não autoriza publicação no PyPI. O envio requer certificação do
bundle associado à tag anotada `v1.0.0rc4`, novos sign-offs e autenticação por
Trusted Publishing/OIDC ou credencial fornecida por canal seguro.
