# Atlas Agent Framework 1.0.0rc5

## Objetivo

A candidata `1.0.0rc5` preserva a identidade pública
`atlas-agent-framework` introduzida no `rc4` e corrige exclusivamente a etapa
final de montagem das evidências de certificação.

## Correção

O montador do bundle ainda procurava os arquivos do meta-package pelo nome
normalizado antigo `atlas_agent`. Ele agora usa `atlas_agent_framework`, em
conformidade com os wheels e sdists efetivamente produzidos.

Um teste de regressão monta o inventário das sete distribuições e confirma a
presença dos 14 artefatos esperados, incluindo:

- `atlas_agent_framework-1.0.0rc5-py3-none-any.whl`;
- `atlas_agent_framework-1.0.0rc5.tar.gz`.

## Escopo preservado

Não há alteração funcional, de API pública, namespace Python, arquitetura,
wire contract, schema de configuração, dependência externa ou política de
segurança. A tag `v1.0.0rc4` permanece imutável como registro da candidata cuja
certificação falhou apenas no montador de evidências.

Esta candidata não autoriza publicação no PyPI. O envio continua dependendo da
certificação integral do bundle, dos sign-offs e de autorização explícita.
