# Atlas Agent Framework 1.0.1rc2

> Candidata certificada e com cinco sign-offs formais. `READY_FOR_STABLE` não
> significa que os artefatos estáveis foram certificados ou publicados.

## Resumo

Esta candidata reabre a certificação da rota não destrutiva até `1.0.1` após
uma falha temporal em um teste da primeira matriz Windows 3.12 da promoção
anterior. A repetição daquele workflow passou, mas o gate conservador ficou
`NOT_READY_TO_PUBLISH` e nenhuma tag estável foi criada.

## Delta da candidata

- versão lockstep das sete distribuições alterada para `1.0.1rc2`;
- maior margem temporal no teste de timeout de seleção em streaming;
- documentação e metadados de release atualizados.

O teste continua exigindo timeout durante a seleção do modelo, antes de
invocar o streaming. Não há mudança funcional no runtime, API pública,
dependências externas, schema, wire contract ou política de segurança.

## Governança

A tag `v1.0.1rc1` e suas evidências permanecem imutáveis. A nova candidata
passou build, qualidade, certificação da tag e integridade dos artefatos no
primeiro attempt. Jorge Medina confirmou separadamente os cinco sign-offs
vinculados ao commit exato de `v1.0.1rc2`; consulte os
[registros versionados](../evidence/1.0.1rc2/SIGN-OFF-STATUS.md). A publicação
no PyPI requer autorização separada.
